This page is a live demo of org-html-theme, a simple, modern, responsive theme for Emacs Org-mode's HTML export. It exercises every element the theme styles, exported straight from the same examples/demo.org file in the repository, using the theme's own published #+SETUPFILE: line. See the repository's README.md for how to use it in your own files.

6. Math

Euler's identity, inline, is \(e^{i\pi} + 1 = 0\). Org adds MathJax to the page automatically whenever a file has a LaTeX fragment like this one, so this needs no setup in `theme.setup`.
